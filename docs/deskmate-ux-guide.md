## 界面入口

| 页面 | 日常内容 | 展开后可查看 |
| --- | --- | --- |
| 对话 | 输入、回答、执行状态、发送/取消、等待决定卡片、最新成果摘要 | 会话切换、完整工具过程、错误、来源、session/run 标识 |
| 任务 | 内容、一次性/每周、下次时间、待处理数；选中后的执行历史与成果 | 新建/修改表单、完整范围预览、原始证据与内部标识 |
| 记忆 | 内容、类型、待确认/已确认、来源摘要、保存/修改/删除 | 来源会话、运行、资料与修改审计、本次实际召回 |
| 通知 | 全部/待处理/未读/历史筛选、关联任务、时间、主要操作 | 通知与 execution/run/request 的完整关联 |
| 设置 | 工作区、Provider、离线演示、免打扰 | 当前会话与完整工作区信息 |

左侧导航只改变当前页面。运行中的任务仍由唯一后台消费者处理。窗口隐藏继续执行；最小化、托盘恢复、无托盘关闭选择和异步真正退出仍由原 `DesktopApplication` 负责。待确认请求在其他页面有“处理待确认请求”入口；通知继续处理会切回对话并聚焦真正的原卡片。

所有正文以本地控件显示，不自动打开网页、远程图片或执行 HTML。完整工具输出默认收起；聊天流式新增文字不会每次重建整篇文档，阅读上文与选择文本可以继续。

## 三条核心流程

**任务：**聊天发送“明天晚上七点提醒我复习项目笔记”，自动进入任务预览，核对时间、时区、重复和范围后确认。也可从任务页新建；执行资料类型才出现文件、URL、输出及模型策略。改变表单后必须重新预览；迟到的旧预览不会覆盖刚输入的新内容，连续提交时也只接受对应最新表单的预览。保存后回到任务详情。下次时间使用该安排自己的时区，详情保留明确时区。

周期资料任务到期后，在执行历史中允许本次模型调用，再从待处理通知或顶部入口进入权限卡片。本次写入的允许/拒绝仍单独决定。中断、失败和可能写入必须核对原会话、成果与磁盘，再勾选核对并明确发起新尝试；切换执行记录会清除这次核对。查看或关闭提醒不会隐式核对。

**记忆：**发送“请记住，我的周报按结论、依据、行动项排列”，核对内容、类型和来源摘要，再确认保存。选中一条后可直接修改并保存，或删除所选记忆。来源详情按需展开。删除后的独立新会话不再召回该内容，过去的会话与审计继续保留；定时任务不使用前台个人记忆。

**通知：**选择筛选条件，再点击通知行或主要按钮，进入具体执行或原权限卡片。关闭本条提醒只结束提示，取消本次执行保留未来周期；停止整个安排会弹出明确确认，取消当前执行并停用未来周期。确认弹窗保留当时的通知/任务身份，后台继续检查版本、工作区与请求有效性。免打扰在设置页，通知页仅显示当前静音状态。

## 查看 Markdown 成果

任务详情或对话“最新成果”展开后，选择已有成果路径，点击“查看成果内容”。后台只允许当前工作区已有 artifact 记录的 `.md` / `.txt`，解析后的路径必须仍在该工作区内，最大 512 KiB，内容须为 UTF-8 文本。缺失、越界、二进制和过大文件会显示原因。预览以纯文本显示，不加载 Markdown 远程素材，不调用模型或重新执行工具。

预览展示**当前磁盘内容**，不改变历史验证状态。“已回读核对”只对应原 artifact 的 `verified`；运行完成、看过文件和模型声称写完均不构成回读证据。文件可能已被其他程序修改；需要新的执行核验时，仍从正常任务提出请求。

切换成果文件、执行记录、会话或工作区后，旧预览会清空；即使两次执行使用相同路径，也需要再次点击查看。选择不会自动读取文件，迟到的旧结果不会显示在新选择下。提交前复审已补充上述交互回归，以及 Windows 目录联接 / WSL 符号链接的越界读取检查。

## 草稿与兼容

同一工作区切换页面保留对话、任务和记忆编辑内容。聊天草稿按实际工作区路径仅在当前进程内保存，切回时恢复；真正退出不会持久保存未发送草稿。工作区交接期间旧卡片、成果、任务与记忆表单清空，避免把旧范围带到新工作区。任务与记忆的未保存表单不跨工作区恢复。

工作区正在切换时不接受任务修改；后台已切换而旧页面尚未刷新的短暂间隔，旧页面提交也会明确拒绝，不把旧对话、安排或偏好保存到新工作区。收到工作区已变化的提示后，等待页面刷新再操作。

`ChatWindow`、`ScheduleWindow`、`MemoryWindow`、`NotificationWindow` 和原 `show_*` / `navigate_notification()` 入口保留。管理器默认可作为独立 modeless 窗口使用；主窗口传 `embedded=True`，实际使用 QWidget 页面，避免 QDialog 隐藏/恢复时改变焦点。原选项控件的 `currentData/findData/setCurrentIndex` 通过可见列表适配，按钮对象名 `allow/deny/answer` 保留。没有新增执行入口、调度器或事件消费者。
