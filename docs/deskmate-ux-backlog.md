## 必须修复的功能与安全问题

- 刷新不能重建聊天全文导致选择消失；流式追加保持阅读位置。
- 工作区交接期间清空旧展示，聊天草稿按工作区隔离；任务、记忆表单清除旧身份。
- 通知定位必须让权限卡片可见且可聚焦；不能复活过期请求。
- 停止整个安排明确确认，保留一次取消、关闭提醒的独立语义。
- 成果文案只使用实际 artifact 状态，未知写入继续核对；预览不授予新范围、不改变验证状态。

## 需要简化的交互流程

- 五个常驻页面代替默认弹窗；原类名/入口作为嵌入适配保留。
- 任务列表与详情优先，新建/修改时才展示表单；执行类型才出现材料范围。
- 来源、完整执行证据和内部 ID 收起；免打扰移到设置。
- 通知提供待处理、未读、历史及全部筛选，保留已关闭提示的业务处理入口。

## 视觉和布局

- 集中浅色主题、主次按钮、文字状态、统一间距；不使用在线素材。
- 表单整页可滚动，按钮分行，长文本独立滚动；小屏/缩放验证见 verification.md。
- 空列表说明下一步；启动、读取、错误有明确文字。
